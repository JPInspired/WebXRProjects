Check This Network

Before a shared lesson, open this page on a headset connected to the school Wi-Fi that the class will use. It checks everything that shared sessions need, explains anything that needs attention and prepares a report for the IT team.

1. Check This Device

One headset is enough for this part. It takes under a minute.

2. Check Two Headsets Together

This shows whether headsets can reach each other on this Wi-Fi, and how quickly. Open this page on a second headset on the same Wi-Fi. Start the test on one and join it on the other with the code.

3. Report for the IT Team

Every result, with the technical details the IT team needs. Copy it into an email or a support ticket.

What Shared Sessions Need

    Lesson content travels directly between the headsets, inside the school network. The introduction servers only pass short connection notes, and the network check never sends the school’s address anywhere.
